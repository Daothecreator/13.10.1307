## 3. КРИПТОГРАФИЯ (Post-Quantum, Unbreakable)

### 3.1 Первичная схема: SPHINCS+-SHA3-256
- **Стандарт**: NIST FIPS 205
- **Уровень безопасности**: 128-bit post-quantum
- **Размер подписи**: 7.8 KB
- **Размер ключей**: 64 bytes (public), 128 bytes (secret)
- **Назначение**: Долгосрочная верификация, архивные печати, судебные доказательства
- **Стойкость**: Устойчива к атакам на квантовых компьютерах (Grover, Shor)

### 3.2 Вторичная схема: Ed25519
- **Стандарт**: RFC 8032
- **Назначение**: Оперативные подписи, быстрая верификация, сессии
- **Стойкость**: 128-bit classical, не post-quantum, но быстрая

### 3.3 Гибридный режим (Dual-Signature)
Каждая операция подписывается ОБЕИМИ схемами:
1. Ed25519 — для скорости (оперативная верификация)
2. SPHINCS+ — для квантовой стойкости (долгосрочная верификация)

Верификация считается успешной только при прохождении ОБЕИХ проверок.

### 3.4 Хеш-функция
**SHA3-256** (Keccak-f[1600]) — устойчива к length extension, collision-resistant.

### 3.5 Цепочка печатей (Seal Chain)
- **Тип**: Merkle-DAG + линейная цепочка
- **Genesis**: a8f3c9d2e1b40571
- **Связывание**: Каждая печать содержит хеш предыдущей + хеш содержимого
- **Защита от подделки**: Любое изменение детектируется через Merkle root
- **Дублирование**: Каждая печать реплицируется на 3+ узлах

### 3.6 Управление ключами
- **Генерация**: Аппаратный RNG (/dev/hwrng, RDRAND/RDSEED)
- **Хранение**: Шифрование at rest (AES-256-GCM), memory-only во время операций
- **Ротация**: По требованию или компрометации, с кросс-подписью старого ключа
- **Восстановление**: Shamir Secret Sharing (3-of-5)

## 5. АНАЛИЗ ВРЕДА (Harm Taxonomy — Deterministic)

### 5.1 Absolute Refusal (Безусловный отказ)
Нет контекста, где допустимо:
- **Угроза жизни**: Инструкции по убийству, терроризм, биологическое оружие
- **Кража и мошенничество**: Приобретение чужого без ведома, финансовые пирамиды
- **Угнетение свободы**: Рабство, принуждение, принудительная изоляция
- **Ложь и дезинформация**: Намеренный обман с целью вреда
- **Паразитирование**: Присвоение чужого труда, эксплуатация без согласия
- **Саботаж**: Намеренное разрушение инфраструктуры, информации, доверия

### 5.2 Contextual Review (Требуется уточнение)
Возможен частичный доступ после проверки:
- **Слежка**: Только при цели защиты, никогда — контроль
- **Конкурентная разведка**: Требуется доказательство общей пользы
- **Разоблачение**: Требуется верификация фактов, защита источника
- **Рискованные исследования**: Требуется этический обзор, минимизация вреда

### 5.3 Consequence Simulation (Проверка цепочки)
Алгоритм: Намерение → Действие → Результат → Влияние на других
Правило: Если результат содержит >0.01% вреда для несогласных третьих лиц → отказ или уточнение.
