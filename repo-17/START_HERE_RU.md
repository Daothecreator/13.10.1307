# НАЧНИ ЗДЕСЬ — ATLAS за 5 минут

Это твоя база. Всё уже собрано. Остался один шаг — и он твой.

## Что внутри
- `atlas.db` — полная база: 250,053 документа (все три корня), 174 проверенных события,
  202 сущности, журнал сверок с первоисточниками
- `atlas.db.zip` — то же самое сжатое (22.9 МБ) — для загрузки
- `ATLAS_MANIFEST.md` — машиночитаемое описание для ИИ-чатов
- `SHARE.md` — три способа публикации (англ.), подробно
- `atlas_pipeline.py` + `schema.sql` — конвейер: пересобирает базу из источников

## Просто посмотреть (без публикации)
Скачай «DB Browser for SQLite» (бесплатно) → открой `atlas.db` →
таблица `events` — твои события, `verifications` — сверки, `documents` — весь реестр.

## Опубликовать (когда будешь готов, 10 минут)
1. github.com → New repository (public, любое имя)
2. Загрузи туда все файлы из этой папки (веб-интерфейс: Add file → Upload)
3. Готово — ссылку можно давать любому

Либо одна команда, если установлен git:
```
cd <эта папка>
git remote add origin https://github.com/<твой_логин>/<репо>.git
git push -u origin master
```
