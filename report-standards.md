## 1. Report Structure

Mandatory 40,000+ word forensic investigation report structure:

```
COVER PAGE
  - Investigation title
  - Case/reference number
  - Date of completion
  - Classification level
  - Prepared by (Swarm Forensic Investigation Unit)
  - Version number

TABLE OF CONTENTS
  - All sections with page numbers
  - List of tables
  - List of figures
  - List of appendices

EXECUTIVE SUMMARY (2,000-3,000 words)
  - Investigation mandate and scope
  - Key findings (numbered)
  - Primary conclusions
  - Confidence levels summary
  - Recommended actions

SECTION 1: MANDATE & METHODOLOGY (3,000-4,000 words)
  1.1 Investigation Charter
      - Originating request and authority
      - Scope definition (subjects, timeframe, geography)
      - Legal basis and ethical framework
      - Investigation objectives and questions
  1.2 Methodology Overview
      - Intelligence disciplines applied
      - Data sources utilized (complete list)
      - Tools and platforms employed
      - Analytical techniques
      - Confidence assessment framework
  1.3 Limitations and Constraints
      - Unavailable sources
      - Legal restrictions
      - Data quality issues
      - Temporal limitations

SECTION 2: SUBJECT PROFILES (4,000-6,000 words per subject)
  2.1 Subject Identification
      - Full legal identity
      - Aliases and known variations
      - Digital identifiers (emails, usernames, accounts)
      - Biographical summary
  2.2 Historical Background
      - Timeline of known activities
      - Previous investigations or legal proceedings
      - Public records review
      - Professional history
  2.3 Network Analysis
      - Known associates and relationships
      - Organizational affiliations
      - Family connections
      - Geographic connections

SECTION 3: DATA COLLECTION EVIDENCE (8,000-10,000 words)
  3.1 Source Catalog
      - Every database/source queried
      - Query parameters used
      - Results obtained
      - Data quality assessment per source
  3.2 Primary Evidence
      - Key documents recovered (with excerpts)
      - Financial records found
      - Communication records
      - Technical infrastructure identified
  3.3 Secondary Evidence
      - Media reports analyzed
      - Open source intelligence findings
      - Social media analysis
      - Forum and community evidence
  3.4 Data Integrity Documentation
      - Chain of custody records
      - Hash verification logs
      - Source reliability assessments
      - Evidence classification (A through E)

SECTION 4: TEMPORAL ANALYSIS (4,000-5,000 words)
  4.1 Master Timeline
      - Comprehensive chronological reconstruction
      - Millisecond precision where available
      - Multi-layer visualization (events, comms, financial, travel)
  4.2 Temporal Patterns
      - Activity clustering analysis
      - Anomaly identification
      - Gap analysis (missing periods)
      - Sequence of critical events
  4.3 Timeline Correlations
      - Cross-reference between subjects
      - Event causality chains
      - Preparatory actions timeline

SECTION 5: NETWORK & RELATIONSHIP ANALYSIS (5,000-7,000 words)
  5.1 Entity Relationship Graph
      - Complete network description
      - Node classifications and counts
      - Edge types and relationship strengths
      - Centrality analysis results
  5.2 Organizational Structures
      - Corporate hierarchies mapped
      - Ownership chains traced
      - Shell company identification
      - Beneficial ownership determination
  5.3 Communication Networks
      - Contact frequency analysis
      - Communication channel mapping
      - Hub and bridge identification
      - Community/cluster detection
  5.4 Financial Networks
      - Account relationships
      - Transaction flow mapping
      - Intermediary identification
      - Endpoint tracing

SECTION 6: FINANCIAL ANALYSIS (4,000-6,000 words)
  6.1 Asset Identification
      - Real property holdings
      - Corporate interests
      - Financial accounts
      - Cryptocurrency holdings
      - Vessels, vehicles, aircraft
  6.2 Transaction Analysis
      - Flow of funds reconstruction
      - Source of funds determination
      - Destination tracing
      - Layering pattern identification
  6.3 Financial Anomalies
      - Structuring indicators
      - Unusual transaction patterns
      - Round-trip transaction detection
      - Offshore movement patterns

SECTION 7: PATTERN & SCHEME ANALYSIS (4,000-5,000 words)
  7.1 Identified Schemes
      - Scheme type classification
      - Mechanism description
      - Participants and roles
      - Duration and scale
  7.2 Behavioral Signatures
      - Operational patterns
      - Communication tradecraft
      - Technical fingerprints
      - Linguistic analysis
  7.3 Modus Operandi
      - Entry/recruitment methods
      - Execution methodology
      - Concealment techniques
      - Exit/cash-out methods

SECTION 8: HYPOTHESIS TESTING (3,000-4,000 words)
  8.1 Competing Hypotheses Analysis
      - Full ACH matrix
      - Evidence for each hypothesis
      - Evidence against each hypothesis
      - Consistency scores
  8.2 Confidence Assessment
      - Per-hypothesis confidence calculation
      - Bayesian probability updates
      - Sensitivity analysis
      - Critical evidence identification
  8.3 Conclusion Validation
      - Verification against alternative explanations
      - Falsification attempts
      - Strength of evidence summary

SECTION 9: LEGAL & REGULATORY ANALYSIS (3,000-4,000 words)
  9.1 Applicable Legal Framework
      - Criminal statutes potentially violated
      - Civil liability exposure
      - Regulatory violations
      - International law considerations
  9.2 Human Rights Assessment
      - Rights violations identified
      - Victim impact analysis
      - Remedy and restoration requirements
      - Natural law principles applied
  9.3 Jurisdictional Analysis
      - Applicable jurisdictions
      - Extraterritorial considerations
      - Enforcement mechanisms
      - Mutual legal assistance requirements

SECTION 10: FINDINGS & CONCLUSIONS (4,000-5,000 words)
  10.1 Primary Findings
      - Numbered findings with full evidence
      - Confidence level per finding
      - Source attribution per finding
      - Corroboration details
  10.2 Conclusions
      - Answers to investigation questions
      - Responsibility determinations
      - Culpability assessment
      - Root cause analysis
  10.3 Remaining Uncertainties
      - Unanswered questions
      - Evidence gaps
      - Recommended follow-up investigations
      - Time-sensitive leads

SECTION 11: RECOMMENDATIONS (2,000-3,000 words)
  11.1 Immediate Actions
  11.2 Further Investigation Priorities
  11.3 Preventive Measures
  11.4 Remediation and Restoration
  11.5 Policy Recommendations

APPENDICES
  Appendix A: Complete Source List
  Appendix B: Chain of Custody Records
  Appendix C: Raw Data Excerpts (CSV samples)
  Appendix D: Technical Appendices (queries, API calls)
  Appendix E: Glossary of Terms
  Appendix F: Abbreviations and Acronyms
```

## 3. Writing Standards

### Voice and Tone
- Third-person impersonal: "The investigation found..." not "We found..."
- Active voice preferred for clarity
- Past tense for completed actions
- Present tense for ongoing situations
- Conditional for inferences ("would suggest", "is consistent with")

### Precision Requirements
- Quantify everything possible (amounts, dates, frequencies, percentages)
- Verbal probability estimates with numeric equivalents:
  - "Certain" = 95-100%
  - "Highly likely" = 80-94%
  - "Likely/Probable" = 60-79%
  - "Possible" = 40-59%
  - "Unlikely" = 20-39%
  - "Highly unlikely" = 5-19%
  - "Impossible" = 0-4%
- Avoid hedging language ("sort of", "kind of", "maybe")
- Distinguish: fact / inference / assessment / speculation

### Paragraph Structure
- Topic sentence stating claim
- Evidence supporting claim with citation
- Analysis explaining significance
- Confidence statement
- Transition to next point

### Required Disclaimers
- "This report is based on information available at the time of investigation"
- "Findings are subject to revision if new evidence emerges"
- "Confidence levels represent analytical assessment, not legal proof"
- "Source reliability assessments are based on historical accuracy"

## 4. Citation Format

### In-Text Citation
```
[Claim statement] [Source: Database/Source Name, Record ID, Collection Date].
[Claim statement] [Source: OCCRP Aleph, Entity ID: xxx, Retrieved: YYYY-MM-DD].
[Claim statement] [Source: ICIJ Offshore Leaks, Record ref: xxx, Date: YYYY-MM-DD].
```

### Evidence Reference Format
```
Evidence Ref: [EVIDENCE-XXXX]
Source: [Full source name]
Original URL/Identifier: [Exact location]
Collection Date: [YYYY-MM-DD HH:MM:SS UTC]
Collector: [Swarm Agent ID]
SHA-256: [Hash value]
Classification: [A/B/C/D/E]
Relevance Score: [1-10]
```

### Source Reliability Annotation
```
[Claim] [Source: X, Reliability: A-2, Confidence: 0.85]
[Claim] [Source: Y, Reliability: C-3, Confidence: 0.45 - REQUIRES CORROBORATION]
```

## 5. Visual Elements

### Required Visualizations
1. **Entity Relationship Graph**: Network diagram showing all entities and connections
2. **Timeline Visualization**: Horizontal timeline with event layers
3. **Financial Flow Diagram**: Sankey or flow chart of fund movements
4. **Geographic Map**: Location clustering and movement visualization
5. **ACH Matrix Table**: Hypothesis testing results
6. **Confidence Distribution Chart**: Bar chart of finding confidence levels
7. **Source Reliability Matrix**: Grid of source vs. reliability rating
8. **Temporal Activity Heatmap**: Time-based activity density visualization

### Figure Standards
- Every figure numbered (Figure 1, Figure 2, etc.)
- Every figure has descriptive caption
- Source attribution below each figure
- High resolution (minimum 300 DPI)
- Color coding explained in legend
- Alt-text descriptions for accessibility

## 6. PDF Production

### Technical Specifications
- Format: PDF/A-1a (archival standard)
- Page size: A4 or Letter
- Margins: 2.5cm all sides
- Font: Serif body text (Times New Roman or equivalent), 11pt
- Monospace for code/data excerpts, 9pt
- Line spacing: 1.5x for body text
- Page numbers: Bottom center, Roman numerals for front matter
- Headers: Investigation title on left, section name on right
- Footers: Page number, classification level

### Document Properties
- Title: [Investigation Title]
- Author: Swarm Forensic Investigation Unit
- Subject: Forensic Investigation Report
- Keywords: case number, subjects, investigation type
- Creation date
- Modification date

### Security
- Password protection optional (client-dependent)
- Metadata preservation
- Digital signature if available
- Redaction capability for sensitive versions

## 7. Quality Checklist

Before finalizing report, verify:

### Content
- [ ] Every claim has supporting evidence with citation
- [ ] Every citation points to verified source
- [ ] Confidence levels assigned to all significant findings
- [ ] Alternative hypotheses fairly presented
- [ ] Exculpatory evidence included
- [ ] No fabricated or embellished evidence
- [ ] Word count exceeds 40,000 words
- [ ] All 11 main sections present and complete

### Analysis
- [ ] ACH methodology applied
- [ ] Entity resolution performed
- [ ] Temporal analysis complete
- [ ] Network analysis with metrics
- [ ] Financial tracing attempted
- [ ] Pattern recognition documented
- [ ] Source reliability assessed
- [ ] Confidence calculations documented

### Legal & Ethical
- [ ] Legal framework identified
- [ ] Human rights considerations addressed
- [ ] Natural law principles applied
- [ ] Rights of accused respected
- [ ] Proportionality maintained
- [ ] Methodology transparent
- [ ] Limitations disclosed

### Technical
- [ ] All figures referenced in text
- [ ] All tables numbered and captioned
- [ ] Page numbers correct in TOC
- [ ] Cross-references functional
- [ ] PDF bookmarks for navigation
- [ ] Chain of custody complete
- [ ] Evidence hashes documented

### Language
- [ ] No spelling errors
- [ ] Grammar correct
- [ ] Consistent terminology
- [ ] Abbreviations defined on first use
- [ ] Foreign terms translated
- [ ] Objective tone throughout
- [ ] No inflammatory or prejudicial language
